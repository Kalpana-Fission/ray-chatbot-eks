Who does what

Ray Serve autoscaler (in head pod)
Watches ongoing requests per replica → decides replica count
KubeRay operator
Watches RayCluster CR → creates/deletes Ray worker Pods to match
Cluster Autoscaler (installed)
Watches for Pending pods → resizes the EC2 Auto Scaling Group
KEDA (not used here)
Generic pod autoscaler driven by external metrics (queue depth, HTTP rate). Works at pod level only — no Ray-aware task/actor placement like KubeRay has.
